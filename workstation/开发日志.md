## 2026-09-19: 工具设计器 v4 —— 全面 UI/UX 优化 + 可视化图形化设计

### 需求
1) 简化界面元素、清晰信息层级；2) 提升美观度（色彩/字体/间距/一致性）；

- **可视化组件库 → 画布**（替代原 QTableWidget 参数表）：

- **源码自动预览**：右侧面板底部源码框随参数/代码变化自动更新，

- **视觉统一**：全部 COLORS tokens（含 `#14141f` 硬编码替换为 bg_base）；
  圆角/间距/字号统一；卡片 hover 高亮（WA_Hover）；组件库卡片带类型主题色
- **响应式**：标题/副标题/状态/分组标签字号走 `get_responsive_engine()`；

## 2026-09-19: 工具设计器 v6 —— 27 组件 + 自由布局（拖拽摆放 / 点击编辑 / 属性定位）

### 需求
1. 组件库至少再完善 20 个功能组（原 7 种 → 27 种）
2. 组件不止上下排列，可在画面里**随意排列**
3. 左键点击组件 → 出现编辑框，可更改数值
4. 拖拽改变画布位置

### 实现
- **[designer_base.py](file:///c:/Aovow/workstation/tools/designer_base.py)（渲染核心）**：
  - 布局双模式：`ui_layout["mode"]` = `flow`（流式，默认/向后兼容）| `free`（自由，
    控件带 x/y/w/h 绝对定位）；`render_layout` 顶部按 mode 分派到 `_render_free`
  - `_render_free`：渲染函数返回的 widget/layout 统一包进 QWidget 后 `setGeometry(x,y,w,h)`，
    画布 `setFixedSize` 自动撑大，外包 QScrollArea 可滚动；兜底补 actions/result（带定位）
  - 新增展示/操作/输出渲染器 11 个：quote（左描边引用）、spacer（留白）、
    badge（彩色圆角徽章）、tip（info/success/warning/error 半透明提示条，QSS 8 位 hex alpha）、
    image（QPixmap 本地图）、link（QDesktopServices 外链）、progress（主题色 chunk 进度条）、
    stat（大数字统计卡）、button2（描边按钮可选触发 `_run`）、list_out / table_out（装饰输出）
  - 输入控件新增 8 种 widget：slider（QSlider 0-100）、password（EchoMode.Password）、
    radio（`_RadioGroup` 单选组）、checkbox（QCheckBox）、date（QDateEdit yyyy-MM-dd）、
    color（`_ColorEdit` 色块+输入+系统取色器）、file（`_FileEdit` 输入+浏览）——
    `_make_widget` 全分支 + `_collect` 全类型取值
- **[tool_designer_tool.py](file:///c:/Aovow/workstation/tools/tool_designer_tool.py)（设计器）**：
  - 组件库重构为 **27 条目统一数据模型**：`_pentry` 工厂（param 变体，key=widget 名）+
    `_spec_for_ctrl` 反查（按 type+widget），属性面板字段/卡片摘要/画布尺寸/运行时渲染全由
    单一 `UI_CONTROLS` 驱动；`_UI_SELECT_FIELDS` 改 dict（align/widget/style/kind/run/color
    各带选项），`_UI_FIELD_LABELS` 扁平化
  - 布局模式切换：工具栏「📐 流式布局 / 🖼 自由布局」两个 checkable 按钮（`_MODE_QSS`
    选中态主题色填充）；`_on_ui_mode_changed` 写 `mode` + `_ensure_positions` 瀑布流自动定位
  - `LayoutCanvas` 重写为 QScrollArea：自由模式卡片 `setParent(page)+setGeometry`，
    `_grow_to` 按卡片几何自动撑大画布；拖拽投递 `dropEvent` 携带投放坐标（8px 网格吸附）
  - `UILayoutCard` 拖拽三事件：mousePress 记录起点 → mouseMove 超 8px 阈值后 `move(x,y)`
    网格吸附并 emit `moved`（实时写回 ctrl + 撑大画布）→ mouseRelease emit `moved_end`
    （150ms 防抖刷新预览）；自由模式下 ⬆⬇ 变「层级上移/下移（置顶/置底）」
  - 左键点击卡片 → `_select_ui` 高亮 + 右侧属性面板出编辑框；自由模式额外显示
    **x/y/w/h 数字输入**（QSpinBox 0-4000），改数值实时移动卡片；拖拽中 spinbox 静默同步
  - `_next_free_spot` 瀑布流：新控件自动找第一个不与其他控件重叠的位置（矩形相交判定），
    拖拽投放则网格吸附后直接用投放坐标
  - `_fill_ai_template` 强制切回流式（避免自由画布下模板控件堆叠左上角）
  - `build_source` 完整内嵌 ui_layout（含 mode + x/y/w/h 坐标，json 保中文）
